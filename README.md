# Portafolio Profesional - María José Erazo Muñoz

Portafolio web interactivo de alto impacto visual y diseño moderno (Dark Mode & Glassmorphism), construido con tecnologías nativas (HTML5, CSS3 y JavaScript).

## 🚀 Características
- **Diseño Responsivo:** Adaptado perfectamente para celulares, tablets y computadores.
- **Terminal Interactiva:** Consola integrada en JavaScript para consultar información de manera original.
- **Sección de Proyectos:** Destacando *Green Task* y su arquitectura de base de datos.
- **Enfoque Humano:** Inclusión de habilidades blandas y pasatiempos conectados con la creatividad UI.

## 🛠️ Tecnologías
- HTML5 (Estructura Semántica)
- CSS3 (Variables, Flexbox, Grid, Animaciones)
- JavaScript (Interactividad y Consola Virtual)
